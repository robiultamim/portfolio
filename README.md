# Robiul Islam Tamim — Personal Portfolio

Live Website: [https://robiultamim.github.io/portfolio](https://robiultamim.github.io/portfolio)

A clean, modern, and high-performance personal portfolio website for **Robiul Islam Tamim** (Software Developer | Full-Stack & Applied AI), built with an Apple-inspired glassmorphic aesthetic, interactive 3D elements, and responsive layout.

---

## ✨ Key Features

- **Apple-Inspired Design Language:** Minimalist typography, frosted glass (`backdrop-filter: blur`), and vibrant multi-stop gradient accents.
- **Dark & Light Mode:** Default light mode with seamless one-click toggle to true-black dark mode (persisted via `localStorage`).
- **Interactive Coverflow Skills Carousel:** Front-and-center card showcase with 40% faded peeking neighbor cards, click-to-center navigation, dot indicators, and mobile swipe gesture support.
- **Interactive 3D Tilt Cards:** Project cards respond dynamically to mouse movement with 3D perspective rotation and cursor-tracking radial glow.
- **Curated Projects View:** Showcases top projects with an expandable "See More" toggle for additional work.
- **Web Audio UI Sound Effects:** Subtle, Apple-style interactive feedback chimes for clicks, card hovers, nav tabs, and theme switching (with a global mute toggle).
- **Fully Responsive:** Optimized across mobile, tablet, and widescreen desktop displays.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS3** (Custom Properties, Flexbox, CSS Grid, Glassmorphism)
- **Vanilla JavaScript (ES6+)**
- **Web Audio API** (Synthesized sound engine)
- **Google Fonts** (Inter)
- **GitHub Pages** (Hosting & Continuous Deployment)
